# 练习（Exercises）

11 个练习，按主题分成 4 个板块，每题一个目录、独立提交。

## 板块一 · Git / 版本控制
- `e01-git-alias` —— 配置 git 别名 `git graph`
- `e02-gitignore` —— 全局 gitignore 忽略 `.DS_Store`
- `e03-git-stash` —— git stash 暂存流程

## 板块二 · Shell 入门
- `e04-ls-permissions` —— `ls -l` 的权限字符
- `e05-glob` —— glob 通配符
- `e06-quoting` —— 单引号 / 双引号 / ANSI-C 引号区别
- `e07-redirection` —— stdout / stderr 重定向

## 板块三 · Shell 脚本
- `e08-check-script` —— 编写并运行 `check.sh`
- `e09-backup-date` —— 备份文件，文件名带当天日期

## 板块四 · 数据处理
- `e10-awk-swap` —— `awk` 交换两列
- `e11-find-xargs` —— `find` + `xargs` 统计行数

> 每个练习目录内有 `README.md` 说明和可运行的 `demo.sh`，进入目录执行 `bash demo.sh` 即可。
