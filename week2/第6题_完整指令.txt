【2】新建三个文件
═══════════════════════════════════════
8. 左侧「项目」面板里，右键 q06 文件夹 → 新建 → Python 文件
   名字填 math_utils，回车，然后把下面整段粘贴进去：

def total_price(price: float, count: int) -> float:
    return price * count

9. 同样方法再建 app.py，粘贴：

from math_utils import total_price

print(total_price(12.5, 4))

10. 同样方法再建 test_math_utils.py，粘贴：

from math_utils import total_price


def test_total_price():
    assert total_price(12.5, 4) == 50.0

   ✅ 截图点 2：左侧「项目」面板，能同时看到 math_utils.py / app.py / test_math_utils.py 三个文件

═══════════════════════════════════════
【3】跳转到定义（total_price 在哪里？）
═══════════════════════════════════════
11. 双击打开 app.py。里面一共有两处写了 total_price：
      · 第 1 行：from math_utils import total_price
      · 第 3 行：print(total_price(12.5, 4))
    把鼠标光标点在第 3 行 print(...) 里面那个 total_price 中间。
12. 按住 Ctrl 键，鼠标左键点一下这个 total_price（或直接按 Ctrl+B）。
    它会自动跳到 math_utils.py 里 def total_price(...) 那一行，说明跳转成功。

   ✅ 截图点 3：跳转后 math_utils.py 里 def total_price 这一行打开的样子

═══════════════════════════════════════
【4】查找引用
═══════════════════════════════════════
13. 光标仍放在 total_price 上，按 Alt+F7（或菜单：编辑 → 查找用法）
    下方会弹出「查找」结果面板，列出 total_price 出现在哪些文件、哪些行。

   ✅ 截图点 4：这个「查找」结果面板

═══════════════════════════════════════
【5】重命名符号
═══════════════════════════════════════
14. 光标放在 total_price 上，按 Shift+F6（或菜单：重构 → 重命名）
    输入新名字 calculate_total，回车。
    三个文件里的 total_price 会全部自动改成 calculate_total。

   ✅ 截图点 5：重命名后，某个文件里已经变成 calculate_total 的样子
     （改完后三个文件内容仍然是配套的，可以直接留成 calculate_total）

【6】用 ruff 和 pytest 跑开发反馈（PyCharm 内置终端）
═══════════════════════════════════════
15. 底部打开终端：菜单 视图 → 工具窗口 → 终端（或快捷键 Alt+F12）
16. 在 app.py 第 1 行上面加一行 import os（PyCharm 默认自动保存，不用手动存）
17. 在终端里敲：ruff check
    会提示 os 未使用，这是正常的，题目就是要这个效果。

   ✅ 截图点 6：ruff check 报「os 未使用」的输出

18. 把 app.py 里刚加的 import os 删掉
19. 终端里再敲：ruff check
    这次干净通过、没有报错。
20. 终端里敲：pytest
    应该显示 1 passed。

   ✅ 截图点 7：pytest 显示 1 passed 的输出
